## Who we are

Didactika is a **technology and educational innovation lab** building open source projects that drive digital learning.

We believe in free, robust and scalable educational infrastructure, able to meet today's challenges of usability, interactivity and integration. Our goal is to build **production-ready** solutions that serve educational institutions, developers and communities committed to free software alike.

> At Didactika, we turn open source into better opportunities to learn.

## Contributing

1. Open an issue to report a bug or propose an improvement.
2. Fork the repository and create a branch for your change.
3. Follow the project's conventions — Moodle coding standards in the PHP plugins, strict TypeScript in the NPM packages.
4. Include tests (PHPUnit or the package's own runner) with your pull request.
